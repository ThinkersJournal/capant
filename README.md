# CapAnt

A capability engine: developers declare NEEDS in order of importance, providers declare what they can do, CapAnt returns the providers that satisfy the needs, with evidence.

Status: design phase (version 0.0.6). See `ROADMAP.md`.

Part of the ant family of shared building blocks (names and rulings: PORTFOLIO-ROADMAP.md in the PM's tree). Licensed under MIT OR Apache-2.0.
